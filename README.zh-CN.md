# skill-install-workflow

AI Agent Skill 安装、升级、验证与治理工作流。

## 项目背景

随着 AI Agent 工作流扩展，Skill 容易出现：

- 多目录重复安装；
- 同一 Skill 多版本并存；
- Git 来源丢失；
- 更新不可追踪；
- 不同 Agent 环境不一致。

本项目将 Skill 安装从简单文件复制转变为可审计、可复现的治理流程。

## 核心理念

> LLM 负责判断，工作流负责执行，验证机制负责确认。

## 工作流程

```text
安装请求
 ↓
来源解析
 ↓
候选 Skill 检查
 ↓
重复检测
 ↓
版本比较
 ↓
功能重叠分析
 ↓
AI 推荐决策
 ↓
风险判断
 ↓
安装与验证
```

## 设计原则

- 一个 Skill，一个事实来源；
- 避免重复安装；
- 保留 Git 来源信息；
- 优先 SymbolicLink；
- AI 判断与文件操作分离。

目标是建立长期稳定、可维护的 AI Agent Skill 基础设施。
